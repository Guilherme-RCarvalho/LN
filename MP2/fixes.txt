To evaluate the performance of your model, you can use the compute_metrics function in the Trainer class. This function takes a EvalPrediction object as input and returns a dictionary containing your evaluation metrics.

First, you need to define a function that calculates the metrics you’re interested in. Since you’re working on a multi-class classification problem, accuracy might be a good choice. You can use the accuracy_score function from the sklearn.metrics module to calculate it.

Here’s an example:

from sklearn.metrics import accuracy_score

def compute_metrics(eval_pred):
    logits, labels = eval_pred
    predictions = np.argmax(logits, axis=-1)
    return {'accuracy': accuracy_score(labels, predictions)}
Then, you can pass this function to the Trainer:
